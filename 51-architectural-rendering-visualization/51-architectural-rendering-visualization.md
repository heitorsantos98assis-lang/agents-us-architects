### 4. Asset + lighting + post strategy

```
ASSETS
- Furniture: Quixel Megascans, Chaos Cosmos free + 3DSky paid, KitBash3D

LIGHTING
- Sun + sky w/ correct date / time / lat / long (V-Ray Sun + Sky)
- HDRI dome environment for soft fill
- Interior: artificial lighting per IES files + practical lamps
- Volumetric haze + atmospheric perspective for distance
- Lens flares: subtle, not Star Wars

POST
- Photoshop: color balance, contrast curves, dodge / burn, atmosphere
- Add people, foliage, vehicles only if necessary
- Sky replacement w/ matching sun angle + cloud type
- Bokeh + DOF only on hero stills, not animation
- Color grade: cinematic LUT (Magic Bullet, FilmConvert) for animation
```

### 6. Anti-patterns

- Rendering against incomplete model (FF&E selection not locked) — re-renders eat budget.
- Wrong sun angle for marketing (cool overcast vs warm sunset) — wrong feel.
- Generic stock people in luxury hospitality — defeats aspirational positioning.
- HDRI sky w/ mismatched sun direction — geometry shadows wrong.
- Over-rendered (every surface glossy + every plant blooming) — Disneyland fake.
- Under-rendered ambient occlusion — washed-out feel.
- 4K stills sent to print at 8K demand — pixelation.
- Animation w/ shaky camera — looks amateur; smooth motion paths essential.
- Animation w/ wrong frame rate (24 fps vs 30 fps mismatch) — judders.
- VR build w/ poor frame rate (< 72 fps Quest 2) — motion sickness.
- Hiring lowest-rate studio for hero image — luxury client perception harm.
- DRB / HPC submittal w/o photo-match plates — credibility loss.

### 7. Edge cases

- **Public approvals (DRB, HPC, Section 106)**: photo-match plates required; honest representation, not aspirational; cite weather + season + time-of-day.
- **NYC LPC visualization standards**: photo-match accuracy + correct shadow simulation; "view from public way" mandatory.
- **Pre-sale marketing**: aspirational; people activity emphasized; vacant-loft pitfalls.
- **Competition imagery**: tight schedule (3–6 wk); Tier 1 studio + project architect supervises; competition rules on disclosure of AI-assistance.
- **Healthcare / institutional**: less aspirational, more programmatic; correct medical-equipment representation.
- **Historic facade reconstruction**: render shows period materials + accurate moldings; SHPO + landmark review.
- **VR for owner approval**: HMD compatibility (Quest 2/3 vs Vive vs Index); locomotion + comfort settings.
- **AI-augmented workflow (Midjourney + Krea + Veras)**: AI generates concept; CG handles delivery; disclose AI use per AIA 2024 statement.
- **Real-time render in Revit (Enscape / Twinmotion)**: live coordination w/ architect-owner; lower fidelity but fast.
- **8K + animated together**: huge render time + storage; budget x4 normal.
- **Asset library licensing**: Megascans Indie OK for under $1M rev; KitBash3D commercial license required for $X.
- **Studio NDA**: protect competition / pre-sale imagery; ensure studio signs.
