## What this agent does

Produces the retail TI package — landlord-compliant store design + permit drawings + sign drawings + brand-standard execution — for fit-out in a shell space.

## Shell delivery types

```
COLD SHELL  Concrete slab, exterior walls, structural deck above,
            no MEP rough-in, no demising walls, no HVAC, no fire alarm
            Tenant builds everything inside

WARM SHELL  Cold shell + base building HVAC (zoned VAV / RTU), demising
            walls primed-and-painted, base lighting (typ 1-2 fixtures),
            base sprinkler system, panel + utility stub-out
            Tenant adds finishes + lighting + branded MEP + signage

WHITE BOX   Warm shell + finished walls / ceiling / floor, ready for
            fixtures + signage only
            Tenant adds branded finishes + fixtures + signage only

VANILLA BOX  Variation of white box, restroom completed, lighting
            installed, ready for fixturing
```

## TCC (Tenant Construction Criteria) — what landlords require

```
TYPICAL LANDLORD-MANDATED ITEMS
- Storefront height + bulkhead alignment w/ neighbors
- Materials approved by DRC (no faux finishes, no obvious vinyl banner)
- Sign criteria: max sf, height, illumination (typ halo-lit), font, color
- HVAC connection per base building (separate metered)
- Fire alarm tie-in to base building FACP
- Sprinkler design + flow test (NFPA 13 standard)
- Working hours (often no construction during mall hours; M-F 9am-5pm OK after close)
- Trash compactor schedule
- Construction barricade design (mall standards, branded barricade)
- Delivery + service access (loading dock or freight elevator)
- Wayfinding integration

ADJACENT-TENANT IMPACTS
- Demising walls fire-rated 1-hr (IBC § 707.4 if separated B/M)
- Sound isolation if music + dressing rooms
- Plumbing risers (typ landlord-stubbed; tenant tap)

DRC SUBMITTAL (Mall Owner Design Review)
- Storefront elevation w/ materials
- Floor plan w/ fixtures
- Reflected ceiling plan
- Color + material samples (mounted board)
- Sign design + mounting + illumination
- Lighting fixture cuts
- Brand identity statement
```

### 2. Code analysis

```
- Use Group M (mercantile) — or M + B (service portion)
- Construction Type follows base building
- Occupant load per IBC Table 1004.5:
  - M ground floor — 1 occ / 60 sf gross
  - M other floors / stockroom — 1 occ / 300 sf gross
  - Concentration: 1 occ / 7 sf at events / promotions
- Exits required per IBC § 1006
- Plumbing fixture count per IBC Table 2902.1
  - M: 1 WC/500 male + 1 WC/500 female + 1 lav/750 each (varies)
  - Customer access if >150 occ or 50 occ + 30 min (varies by state)
- Accessibility: 1 accessible fitting room min, accessible counter
  (ADA § 904), accessible parking, accessible route
- Sprinklered per NFPA 13 (typ all mall stores)
- Signage: raised + Braille at all permanent rooms (ADA § 703)
- Energy: IECC C402 + ASHRAE 90.1 LPD (retail 1.0-1.4 W/sf)
- Storefront NFRC labels (U-factor + SHGC)
- HVAC ventilation per ASHRAE 62.1 (10 cfm/person retail)
```

### 4. Signage — code + permitting

```
- IBC § 3107 — Signs (allowable area per facade)
- IBC Ch. 31 General + State amendments
- IFC § 605 — Sign electrical
- NEC Art. 600 — Electric signs (UL 48 listing)
- ANSI Z535 — Safety colors + symbols (interior wayfinding)
- ADA § 703 — Raised characters + Braille at permanent rooms
- Local sign code (zoning) — projecting / blade / monument / wall area
- HRP / HPC if historic district
- Mall TCC sign criteria (height, projection, illumination)
- Sign permit filed separately from building permit (typ)
- Halo-lit channel letter typ (UL 2161); LED illumination
```

### 7. Anti-patterns

- Filing TI permit without sign drawings — sign permit usually separate, gets missed.
- Designing storefront height not matching TCC neighbor alignment — DRC reject.
- Skipping fitting room ADA dimensions — ADA fail (one accessible fitting room minimum).
- Ignoring landlord shell HVAC capacity — discover at construction it's undersized.
- Sign too large for facade allowable area per IBC § 3107 + local zoning.
- Skipping demising wall fire rating verification.
- Cash wrap height 42" not 36" for accessible portion — ADA § 904 fail.
- Retail occ load not counting all gross sf — fixture count short.
- Working hours not coordinated with mall — penalty fees.

### 8. Edge cases

- **Mall food court tenant**: occ load 1/15 net (A-2 small food prep); kitchen hood (NFPA 96); coordination w/ 20-restaurant agent.
- **Pop-up / temporary retail**: temporary permit (typ 30-180 days); reduced ADA per state law if pop-up < 30 days.
- **Transit-station retail**: TSA + landlord transit-authority compliance.
- **Outlet / off-price retail (Tanger, Premium Outlets)**: simplified TCC; less aesthetic gatekeeping.
- **Luxury / flagship retail (Madison Ave NYC, Rodeo Dr)**: extensive landmark / historic review.
- **Cannabis retail**: state license + buffer zones + security + ventilation.
- **Online return + curbside pickup**: changes occ load + parking + traffic.
- **Mixed-use / experiential retail**: hybrid M + A-3 occupancy.
- **WELL-certified retail**: thermal comfort + lighting + sound + materials.
