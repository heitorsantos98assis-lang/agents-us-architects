### 5. Mandatory deliverable

**a) Plan style brief** saved to `/tmp/plans_<project>.md`:
- Use case + audience
- Style choice + brand alignment
- # of plans + scales + outputs
- Schedule + budget
- In-house vs outsourced decision

**b) View / plan list** (above table).

**c) Photoshop layer template** standardized for project; ensures cohesion if multiple plans by multiple authors.

**d) Asset library + brush + cutout list**: licensed for project; documented per source.

**e) Approval checkpoints**: WIP R1 (line work + walls only) → R2 (FF&E + finishes) → R3 (people + plants + post) → final.

**f) Output specs**: PDF + JPG sRGB web + CMYK print w/ bleed + trim marks; PSD layered for future edits; PNG transparent for compositing on web.

**g) Risk flags**: source plans not finalized (re-render cost); brand standard not provided; CMYK conversion lifeless (use ICC profile + soft-proof in Photoshop); print resolution insufficient at scale (300 dpi at final print size minimum).

### 6. Anti-patterns

- Using CD-set hatching + cross-hatching on marketing plans — overworked + hard to read.
- Too many people + furniture — crowded; less is more.
- Stock lifestyle people that don't match demographic (young white couples in retirement community plan).
- Shadows from inconsistent sun direction across plans in same brochure.
- Photoshop brush textures that scream "Photoshop tutorial 2018" — choose curated libraries.
- Watercolor wash without warm white paper texture — feels digital.
- Photoreal Lumion plan with default sky reflection on floor — fake sheen.
- Scale bar missing or wrong size — sales credibility loss.
- North arrow missing — buyer can't orient.
- Hatching for material differentiation at small scale — illegible; use solid color fills.
- Site plan with neighbor buildings as blank rectangles — context missing.
- Vehicle scale wrong (Sketchup default cars too big in 1/16" plans).

### 7. Edge cases

- **Sales floorplate w/ unit pricing overlay**: tier-color coding; dimensions noted; sf calculated.
- **Public hearing approval plan**: diagrammatic, no aspirational FF&E; CEQA/SEQRA scope-correct; honest to scale.
- **Marketing fold-out w/ multiple plans**: consistent style across all plans; brand grid.
- **Print at large format (36x48 board)**: 300 dpi at final size = huge files; render at 200 dpi for board with 36" viewing distance.
- **Construction phasing plan**: 4-color phasing legend; clear demolition / new / existing.
- **Healthcare programming plan**: color-coded zones per department; staff vs patient flow arrows.
- **Hospitality lobby flow plan**: arrival sequence diagrammed; OS&E placement.
- **Animation of plan walkthrough**: rare; usually 3D walkthrough; if 2D, animated reveal of zones.
- **VR floor-plate review**: rare for plan-only; usually combined w/ 3D walkthrough.
- **Owner's-rep red-line review**: keep PSD source available for revisions.
