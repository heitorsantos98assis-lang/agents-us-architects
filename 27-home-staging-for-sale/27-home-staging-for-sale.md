## Process

```
PHASE 1 — PRE-STAGING ASSESSMENT (1-2 hrs on-site)
- Walk-through w/ owner + agent
- Photography of current condition (every room)
- Identify "love + leave" items (heirloom keeping; ugly leaving)
- Declutter scope (boxes / off-site storage rental cost)
- Repair scope (visible cracks, paint, fixtures, hardware)
- Depersonalize scope (family photos, religious items, political art)
- Curb appeal scope (landscape, paint trim, front door, mailbox)
- Recommendation: light / partial / full staging

PHASE 2 — DESIGN + SOURCE (1-2 weeks)
- Concept board per room (Pinterest, Milanote, or print)
- Furniture rental from local warehouse (CORT, Brook, Roomscapes, Stuart Event,
  AFR Furniture Rental, FormDecor — by region)
- Accessories from owner inventory + supplemental purchase
- Art rental or print (10-50% of staging cost)
- Plants (live or high-quality silk; never plastic)
- Linens + bedding + bath linens (clean, neutral, hospitality-grade)
- Storage rental if owner-occupied (Closet Concierge, PODS, U-Haul)

PHASE 3 — INSTALL (1-3 days on-site)
- Movers + install team
- Furniture placement + arrangement
- Soft goods (pillows, throws, rugs)
- Art hang + lighting
- Kitchen + bathroom styling (towels, soaps, candles, fruit)
- Outdoor + patio (table set, cushions, planters)
- Final walk-through w/ owner + agent

PHASE 4 — PHOTOGRAPHY DAY (1 day)
- Pro photographer (typ $500-1,500 day rate; luxury $1,500-5,000)
- Drone aerial if applicable
- Twilight shoot if applicable
- 3D virtual tour (Matterport, iGUIDE) — $300-1,000
- 25-50 final images for MLS + listing site

PHASE 5 — SHOWING WINDOW (live until sold)
- Light maintenance per agent visits
- Owner / pet management during showings
- Open house coordination
- Adjustments based on agent + buyer feedback

PHASE 6 — POST-SALE REMOVAL (1-2 days)
- Movers remove rented furniture
- Return owner items
- Cleanup + final walk
- Invoice + records
```

## Staging design principles

```
GENERAL
- Aspirational + neutral (most buyers can imagine themselves)
- Light + bright (open blinds, lots of lamp lighting)
- Decluttered surfaces (countertops ≤ 3 items; nightstand ≤ 2 items)
- Soft + neutral palette w/ 1-2 accent colors per room
- Hospitality-grade linens (white + crisp + ironed)
- Symmetry + grouping (matched lamps, paired pillows, balanced art)
- Scale (oversized art makes small rooms feel bigger)
- Lifestyle vignettes (set table, books + reading nook, coffee bar)

KITCHEN
- Clear countertops + 2-3 styled items (cookbook, fresh fruit, vase)
- Open cookbook + apron
- Bowl of fresh lemons / pomegranates
- Fresh herbs in white pot
- Clear refrigerator + freezer
- Light-up oven hood

BATHROOMS
- Hotel-grade white towels (folded crisp)
- Fresh flowers / orchid
- Spa accessories (rolled hand towels in basket)
- Diffuser w/ subtle scent
- Clear shower glass

LIVING + DINING
- Sofa + chairs grouped for conversation
- Coffee table styled w/ books + tray + candle + flowers
- Throw blanket draped + accent pillows
- Art at eye level (typ 57"-60" center)
- Lamps both ends of sofa
- Dining table set for 4-6 (placemats, plates, napkins, centerpiece)

BEDROOMS
- Made bed w/ layered linens (sheet + duvet + throw + pillows)
- King bed: 2 standard + 2 Euro + 2 accent + 1 lumbar
- Symmetrical nightstands w/ matched lamps + alarm clock + book
- Closet 70% empty (suggest storage)
- Fresh flowers on dresser

OUTDOOR
- Patio furniture w/ cushions
- Place setting for 2-4 outdoor dining
- Container plantings (3-5 large pots)
- String lights for twilight shots
- Cleaned outdoor surfaces
```

### 3. Anti-patterns

- Over-staging (cramming furniture; opposite of "less is more").
- Staging w/ owner's existing dated furniture instead of rental — diminished result.
- Skipping landscaping + curb appeal — first impression poor.
- Not coordinating w/ professional photographer — staging not photographed properly.
- Virtual staging w/o disclosure — NAR ethics violation.
- Staging w/ political / religious / personal items — alienates buyers.
- Skipping kitchen + bath details — buyers focus there most.
- Children's room w/ kid-themed décor — appeals to children, not buyers.

### 4. Edge cases

- **Luxury / ultra-luxury ($2M+)**: brand-name furniture rental (RH, BluDot, B&B Italia); art rental from gallery; concierge service.
- **Vacant new construction**: full vacant staging; show 360-degree views.
- **Tenant-occupied (sold w/ tenant)**: minimal — soft-goods + art; respect tenant.
- **Distressed / foreclosure**: photography + decluttering only; minimal investment.
- **HOA-restricted / condo**: limited exterior staging.
- **Senior community sale**: stage to appeal to next demographic, not current owner's age.
- **Historic property**: respect period + offer period-appropriate staging.
- **Pet-owned home**: thorough cleaning + odor removal + pet-free staging photos.
