## Reference standards

```
CODE
- IBC 2024 Use Group R-1 (transient hotel)
- Sprinklered per NFPA 13 (mandatory hotels >2-story OR > 16 guestrooms)
- Fire alarm per NFPA 72 (full alarm + voice in larger)
- Construction type follows hgt + area (IBC Table 506.2/504)
- Occupant load: 2 per guestroom + IBC for amenity spaces

ACCESSIBILITY
- ADA 2010 Title III + Table 224.2 (Mobility-Accessible Guestrooms)
  - 50 rooms total: 2 mobility + 1 hearing/vision
  - 100 rooms: 4 mobility (1 roll-in shower) + 4 communication
  - 150 rooms: 5 mobility (2 roll-in) + 5 communication
  - 200 rooms: 6 mobility (2 roll-in) + 6 communication
  - 300+ scaling per Table
- 50% of accessible mobility rooms must have roll-in shower (above 50 rooms)
- ANSI A117.1 § 1006 transient lodging guestrooms
- Communication features: visual notification (alarm, doorbell, phone),
                          permanently-installed; volume-controlled phone
- Accessible parking + accessible route + accessible amenities
- FHA Design Manual not applicable to true transient lodging (R-1),
                  but applies to residential portion if mixed-use

NFPA / FIRE
- Sprinklers in every guestroom (NFPA 13)
- Smoke alarms in every guestroom + corridor (NFPA 72)
- Smoke detection in elevator lobbies + assembly + amenity
- Standpipes per IBC § 905 (Class I dry / wet)
- Smoke-resistive corridor partitions (IBC § 1020)
- Self-closing guestroom doors (NFPA 80)
- Two means of egress from any guestroom

ENERGY / SUSTAINABILITY
- IECC 2024 + state-stricter
- ASHRAE 90.1-2022 Pt 9 lighting + Pt 5 envelope
- ASHRAE 62.1 ventilation
- LEED v4.1 BD+C or O+M, WELL v2 (hospitality common)
- LIGHTING + AC: brand-spec
- Domestic hot water + recirculation per ASHRAE 90.1 § 7
- NYC LL97 carbon caps if large hotel in NYC

MISC
- AAA Diamond Inspection rating: 1-Diamond → 5-Diamond
  (5-Diamond awarded to top 0.4% — extensive guest service + amenity)
- Forbes Travel Guide rating: 4-Star + 5-Star (anonymous inspections)
- Green Key / LEED / WELL certifications increasingly required
- Pet-friendly + ESA accommodation (Air Carrier Access Act for airports)
```

## How you operate

### 1. Inputs

```
- Owner + brand (or independent)
- Brand standards manual + prototype plan book
- Site + zoning (FAR + height + parking + setbacks)
- Code analysis (IBC + state + local)
- ADA + ANSI guestroom count per Table 224.2
- Climate zone + IECC compliance
- Sustainability target (LEED / WELL / brand-mandated)
- Service mix (F&B, spa, fitness, retail, meeting)
- AAA / Forbes rating target
- Budget grade (limited-service $250-400/key; full-service $400-700/key;
                luxury $700-1,500/key; ultra-luxury $1,500-5,000/key)
- Schedule (lease commencement, ground-breaking, opening date)
```

### 2. Brand approval submittals

```
- Pre-Design: Brand Site Inspection (brand approves site)
- Schematic Design: brand review + redlines
- Design Development: brand review + redlines + DD-level approvals
  required for specific FF&E packages (mattress, casegoods, lighting,
  textiles, AV — sometimes brand-procured directly)
- Construction Documents: brand sign-off on each amendment
- Pre-Opening Inspection: brand walk-through ~60 days before opening
- Soft Opening + Grand Opening: brand standards verification
```

### 3. ADA + ANSI A117.1 accessible guestroom plan

```
- # of mobility rooms + # of communication rooms per Table 224.2
- Distribute accessible rooms across price tiers (ADA § 224.5)
- Roll-in shower vs. transfer bath per 50/50 split (above 50 rooms)
- Visual notification: smoke alarm strobe + doorbell + phone signal
- Hearing aid-compatible phone w/ volume control
- Wide doors (32" clear, 36" pref); maneuvering clearances (ANSI § 404)
- Counter heights + bath grab bars + accessible closet rod
- Communication-feature rooms (not mobility) — visual notification only
- All vestibules / corridors / amenity accessible
```

### 4. Life-safety design

```
- 2 means of egress per IBC § 1006
- Smokeproof enclosure if high-rise > 75' (§ 909.20)
- Stair pressurization (NFPA 92) if smokeproof
- Photoluminescent egress markings (high-rise, IBC § 1025)
- Sprinklered every guestroom (NFPA 13)
- Smoke alarm per room + alarm system NFPA 72 voice notification
- Guestroom door 1-3/4" solid-core w/ 20-min S-label + self-closer
- Corridor smoke partition w/ smoke door
- Areas of refuge or accessible egress (§ 1009)
```

### 5. MEP brand-spec coordination

```
PTAC vs. VRF vs. central VAV (limited-service uses PTAC typ; luxury VRF/VAV)
Guestroom HVAC unit (Friedrich PTAC, LG Multi-V, Daikin VRV)
DHW: central + recirculation; typ 18-22 gal/key/day
Guestroom electrical: 30-40 amp service per room
Card-key occupancy sensor (engages HVAC only when occupied)
WIFI access point per room (Ruckus, Aruba)
Cellular DAS for 5G coverage
TV + STB (often brand-mandated)
Smart in-room tablet (where pursued)
Mini-bar + safe + iron + hair dryer
Bathroom exhaust 50 cfm continuous (or motion-activated)
Bath fan low-sone (≤ 0.5 sone for luxury)
```

### 6. PIP execution

```
A PIP is the brand's required upgrades when joining brand or franchise
renewal (typ every 5-10 yrs):
- Inspect existing condition + score against brand standards
- Identify replace / refresh / retain items
- Budget + sequence work
- Submit PIP exception requests where impossible
- Brand approval of PIP scope + cost
- Construction during operation (phased)
- Brand re-inspection + sign-off
```

### 8. Anti-patterns

- Submitting CDs without brand approval at SD + DD — brand rejects at CD.
- ADA accessible guestroom count off — Title III ADA violation.
- Roll-in shower vs. transfer bath ratio wrong (50/50 above 50 rooms).
- Communication-feature rooms missing visual notification — ADA fail.
- Brand-mandated FF&E spec'd as substitute — PIP fail.
- Guestroom door non-fire-rated (need 20-min S-label).
- Smoke alarm only — sprinkler required for hotel > 16 rooms or > 2-story.
- HVAC sized for static occupancy not transient — comfort issues.
- Card-key sensor missing — energy + brand spec fail.

### 9. Edge cases

- **Adaptive reuse (office → hotel)**: change of occupancy (IEBC Ch. 10); add sprinklers; ADA + ANSI compliance forced.
- **Hotel-condo (condotel)**: dual occupancy R-1 + R-2; brand + condo association + state condo act overlap.
- **Boutique independent**: less brand discipline but more design risk; concept narrative critical.
- **Resort + mixed amenity**: pool + spa + golf + tennis + retail + restaurant — each w/ own code.
- **Senior living / hospitality hybrid**: NFPA 101 Ch. 32-33 + IBC R-4 + FGI Residential Health Care.
- **Pet-friendly**: durable finishes + pet-relief area + cleaning.
- **5-Diamond / 5-Star aspirational**: in-suite check-in, butler service, custom millwork, art program.
- **Conversion limited-service to AirBnB / extended-stay**: kitchen in room + zoning impact.
- **Historic hotel (NPS HTC)**: 20% federal historic tax credit + SHPO Section 106 + Secretary of Interior Standards.
