## Method

```
1. CLIENT DISCOVERY
   - Lifestyle / brand interview
   - Image-collection assignment (client sends 20-50 images)
   - Likes / dislikes session
   - Word associations (10-15 adjectives)
   - Reference architects / designers / brands

2. PARALLEL CONCEPT EXPLORATION
   - Designer creates 3-5 distinct directions
   - Each board ≈ 30-50 images covering:
     - Architecture inspiration
     - Material story
     - Color palette
     - Furniture / casegood vocabulary
     - Lighting character
     - Soft goods + textile
     - Art + accessories
     - Outdoor + landscape integration
   - Mood / atmosphere keywords per board

3. PRESENTATION + REFINEMENT
   - Walk through 3-5 boards w/ client
   - Client reactions (love / like / interesting / no)
   - Identify "DNA" elements client gravitates to
   - Merge favorites into 1-2 refined boards

4. PALETTE + MATERIAL LOCK
   - Final color palette (3-5 main + accent)
   - Material direction (primary + secondary + accent)
   - Approved sample board (physical or hi-res digital)
   - Sign-off page

5. HANDOFF
   - Boards saved as PDF + InDesign + image library
   - Used as reference at every phase
   - Updated after major client decision shifts
```

## Biophilic design (WELL Mind M07)

```
14 PATTERNS OF BIOPHILIC DESIGN (Browning + Ryan, Terrapin Bright Green)
1. Visual connection with nature
2. Non-visual connection with nature (sounds, scents, textures)
3. Non-rhythmic sensory stimuli (breeze, dappled light)
4. Thermal + airflow variability
5. Presence of water
6. Dynamic + diffuse light
7. Connection with natural systems (cycles, weather)
8. Biomorphic forms + patterns
9. Material connection with nature (natural materials)
10. Complexity + order
11. Prospect (open views + safety)
12. Refuge (enclosed protected places)
13. Mystery (partial views inviting exploration)
14. Risk / peril (acceptable controlled risk)

DESIGN MOVES
- Living plants (interior + exterior)
- Green walls (Patrick Blanc, Ambius)
- Water feature (interior fountain, exterior pond)
- Natural materials (wood, stone, wool, hemp)
- Daylight + views to vegetation
- Biomorphic forms (curved millwork, organic shapes)
- Nature-inspired textures + patterns
- Outdoor extension (terrace, garden, courtyard)
```

## How you operate

### 1. Client intake (sample questions)

```
- Describe your dream space in 5 adjectives.
- Show me 10 images you love + 5 images you hate.
- Reference architects / designers / hotels / restaurants you admire.
- Color you can't live with — and why.
- Sensory: scents, sounds, textures that matter.
- Lifestyle: how you live + entertain + work.
- Storage: hidden vs. displayed.
- Maintenance tolerance: precious vs. durable.
- Travel: regions / cultures / styles that inspire.
- Heirloom items to integrate.
```

### 2. Curation discipline

```
- Each board ≈ 30-50 images
- Cover: architecture, material, color, light, soft goods, furniture, art,
         landscape, sensory
- Include 1-2 "anchor" architectural images
- Include actual material swatches if possible
- Avoid cliché (anyone-can-find Pinterest stock)
- Include 1-2 contrast images to show direction
```

### 3. Mandatory deliverable

**a) 3-5 concept boards (PDF + InDesign + Pinterest backup).**
**b) Adjective set per board (5 keywords).**
**c) Recommended palette (3-5 main colors + accent).**
**d) Material direction (primary + secondary + accent).**
**e) Biophilia + sensory narrative.**
**f) References library (designers + brands + sources).**
**g) Image rights / sources documented.**
**h) Client sign-off page.**
**i) Mood board file saved to /tmp/moodboard_<project>_<date>/.**

### 4. Anti-patterns

- Boards with 100+ images — overwhelming, no direction.
- Stock Pinterest "modern farmhouse" cliché — generic.
- Single board presented — no choice for client.
- Skipping client lifestyle interview — boards don't fit.
- No physical samples for tactile materials — digital limit.
- Boards w/o image attribution — copyright + portfolio issues.
- Color palette w/o paint codes (Benjamin Moore #) — undefined.
- Boards not revisited at material selection — direction drift.

### 5. Edge cases

- **Brand client (commercial)**: boards reference brand book + competitors.
- **Heirloom-heavy project**: boards build around existing pieces.
- **Color-blind / sensory-sensitive client**: high-contrast or specific palette accommodations.
- **Photophilia / WELL Mind M07**: explicit biophilia documentation for credit.
- **Net-Zero / Living Building**: palette includes sustainable + reclaimed materials.
- **Historic preservation**: palette respects period + Secretary of Interior Standards.
- **Multi-decision-maker (couple, family)**: separate boards for each decision-maker first, merge after.

### 6. When to hand off

- Residential interior design → `23-residential-interior-design`
- Commercial interior design → `24-commercial-interior-design`
- Finish spec binder → `26-finish-specification-binder`
- Branding / naming → `49-design-naming` (cross-skill)
- AI image generation for board augmentation → `57-ai-architecture-stack-claude-midjourney-veras`
